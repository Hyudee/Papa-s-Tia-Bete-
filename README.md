# Papa's Tia Bete

Papa's Tia Bete é um jogo 2D do gênero **Tower Defense com elementos de Roguelike**, desenvolvido em **C++** utilizando a biblioteca **SDL3**.

O jogador assume o papel do Don Saladinho, um guerreiro de alface, o qual precisa proteger a cozinha de uma invasão de ingredientes rebeldes. Para isso, é necessário derrotar inimigos, sobreviver às ondas de ataque e enfrentar chefes cada vez mais fortes enquanto aprimora seu personagem através de um sistema de upgrades.

## Principais recursos

* Sistema de ondas com dificuldade progressiva;
* Chefes com aumento gradual de dificuldade;
* Sistema de upgrades entre batalhas;
* Power-ups de vida e aumento de dano;
* Sistema de pontuação e ranking local;
* Animações em sprites;
* Efeitos sonoros e músicas;
* Interface desenvolvida em SDL3.

## Tecnologias utilizadas

* C++
* SDL3
* SDL3_image
* SDL3_ttf
* Microsoft Visual Studio 2026

## Como executar

1. Baixe a versão mais recente do jogo.
2. Extraia o arquivo `.zip`.
3. Execute `jogo.exe`.

> É importante manter a pasta `assets` no mesmo diretório do executável.
